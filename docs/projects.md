# Projects folder

Edit `src/data/projects.json` to change the cards inside the Projects folder. Each entry has an `id`, `title`, `description`, `tags` array, `url`, and `image` object with `dark`, `alt`, and optional `light`. Keep the current three entries for the three-card layout. Missing light artwork uses dark artwork. URLs currently use example.com placeholders; replace them with real project destinations when ready.

The folder starts closed. Click or press Enter/Space to toggle it; Escape closes it. Cards open their destinations in new tabs. Site theme switching updates glass, card surfaces, and artwork while retaining open state. Mobile opens into a vertical list. Without JavaScript, a static list provides the same content and links.

The centered folder has an Other projects link beneath it pointing to the GitHub repository list.
